## 项目概述

本项目对纽约市黄色出租车（Yellow Taxi）2026年1月的行程记录进行全方位数据分析，包含约**372万条**真实出行记录。通过四个递进式模块，从数据预处理到智能问答，构建了一个完整的出租车出行数据分析流水线。

**核心能力：**
- 自动化数据质量评估与智能清洗（缺失值分级处理、异常值IQR检测、重复去重）
- 多维度可视化分析（出行需求规律、区域热度、车费因素、支付方式对比）
- 机器学习需求预测（PyTorch神经网络 vs 随机森林对比）
- 自然语言交互式问答（关键词+规则意图识别，零代码获取数据洞察）

## 模块详解

### M1: 数据质量报告与清洗

**功能：** 对原始数据进行全面质量评估和智能清洗，生成可复用的清洗后数据。

**核心处理流程：**

| 步骤 | 操作 | 策略说明 |
|------|------|----------|
| 1 | 删除全空列 | 去除没有任何信息价值的列 |
| 2 | 缺失值处理 | 缺失率>60%：删除列；缺失率<5%：均值/中位数填充；5%-60%：中位数填充；类别型：众数填充 |
| 3 | 异常值处理 | IQR方法（四分位距法），低比例用中位数替换，高比例做缩尾处理（Winsorize） |
| 4 | 重复行删除 | 去除完全重复记录，避免统计偏差 |
| 5 | 格式标准化 | 去除字符串前后空格，日期时间字段统一格式 |
| 6 | 特征工程 | 提取时间特征（小时、星期、是否周末/高峰、月份、季度）和衍生特征（小费比率、每英里收入） |

**输出文件：**
- `data_clean.pkl` — 清洗后的数据（项目根目录）
- `outputs/data_quality_report.csv` — 每个字段的缺失率、异常值统计等详细报告
- `outputs/derive.csv` — 衍生特征数据集

---

### M2: 可视化分析

**功能：** 从四个维度对出租车出行数据进行可视化分析，每个维度生成高质量图表。

**分析主题：**

#### 分析1：出行需求时间规律
- 工作日 vs 周末分小时订单量折线对比图
- 星期×小时的订单量热力图
- **洞察：** 揭示早晚高峰双峰模式，量化工作日与周末出行差异

#### 分析2：区域热度分析
- 上下客量TOP10区域柱状图
- TOP5热门上车区域的小时订单量热力图
- 可选：纽约市地图的地理空间可视化（需geopandas + shapefile）

#### 分析3：车费影响因素
- 行程距离与车费散点图（含相关系数）
- 不同时段的中位车费柱状图

#### 分析4：支付方式对比
- 信用卡/现金/弹性车费的平均总费用对比柱状图
- 样本分布统计和业务洞察输出

**输出文件：**
- `outputs/m2_1_demand.png` — 出行需求分析图
- `outputs/m2_2_region.png` — 区域热度分析图
- `outputs/m2_3_fare.png` — 车费分析图
- `outputs/m2_4_payment_avg_total.png` — 支付方式对比图

---

### M3: 机器学习预测

**功能：** 使用两种机器学习方法预测每小时的出租车出行需求量，并进行对比分析。

**方法对比：**

| 特性 | PyTorch 神经网络 | 随机森林 |
|------|-----------------|---------|
| 模型结构 | 三层MLP（1→64→32→1） | 100棵决策树集成 |
| 训练参数 | 500 epochs, Adam优化器, MSE损失 | 默认参数，全核心并行 |
| 适用场景 | 大规模数据下的非线性拟合 | 小样本下的稳定预测 |
| MAE | 约56,159 | 约19,918 |
| RMSE | 约59,682 | 约25,483 |

**分析结论：** 在本任务中（24个时段样本），随机森林表现显著优于神经网络。原因是样本量极小，神经网络的参数量远超样本量容易过拟合，而随机森林的集成策略在小样本上更加稳健。

**输出文件：**
- `outputs/m3_model_metrics.csv` — 两模型MAE/RMSE对比
- `outputs/m3_neural_network_loss.png` — 神经网络训练Loss收敛曲线

---

### M4: 自然语言问答系统

**功能：** 基于关键词匹配和规则引擎的意图识别系统，用户输入自然语言问题即可获得数据分析结果。

**支持的意图类别：**

| 意图 | 触发关键词示例 | 返回内容 |
|------|--------------|---------|
| 数据质量 | "质量"、"缺失"、"异常" | 质量报告摘要 + 文件路径 |
| 数据清洗 | "清洗"、"预处理" | 清洗前后对比 + 清洗后文件 |
| 出行需求 | "需求"、"高峰"、"订单量" | 高峰/低谷时段统计 + 需求图 |
| 区域热度 | "区域"、"上车"、"热门" | TOP5区域 + 热力图 |
| 车费分析 | "车费"、"多少钱"、"费用" | 平均/中位车费 + 散点图 |
| 支付方式 | "支付"、"信用卡"、"现金" | 各方式费用对比 + 柱状图 |
| 模型效果 | "模型"、"预测"、"机器学习" | MAE/RMSE指标 + Loss曲线 |
| 数据概况 | "统计"、"概况"、"多少行" | 数据规模/时间范围等概览 |
| 时间特征 | "特征"、"衍生" | 新增特征列说明 |

**使用示例：**

```
>> 请输入问题: 数据质量怎么样？
[Intent] 识别意图: data_quality
① 数字结论: 共3724889行×21列；有缺失的列3个；缺失率>20%的列1个...
② 文本解释: 数据质量报告已生成。3个字段存在缺失值...

>> 请输入问题: 出行需求有什么规律？
[Intent] 识别意图: demand
① 数字结论: 高峰时段: 18:00（456,234单）；低谷时段: 4:00（12,345单）...
② 文本解释: 出行需求呈现明显双峰模式：早高峰7-9点、晚高峰17-19点订单量最高...
③ 相关文件:
   → outputs/m2_1_demand.png
```

**运行方式：**

```bash
cd src
python m4.py
# 输入 help 查看所有示例问题
# 输入 exit 退出
```
